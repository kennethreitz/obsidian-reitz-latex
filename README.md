# Reitz LaTeX

An Obsidian theme with two modes of mind: **write like iA Writer, read like a LaTeX paper.**

Light and dark modes included. Fonts are embedded, so it works offline with no setup.

## The thinking behind it

Writing and reading are different acts, and they deserve different rooms.

**Editing is inspired by iA Writer.** When you're writing, the theme gets out of the way. Monospaced IBM Plex Mono, a calm, narrow column, and no ornament are there so you're with the words, not the formatting. Markdown stays honest and visible. It's a focused instrument for thinking.

**Reading is inspired by the academic paper.** Switch to reading view and the same note becomes a typeset document. Latin Modern, the Computer Modern descendant TeX made famous, gets generous margins, real hierarchy and the quiet authority of a well-set paper. Your notes stop looking like drafts and start looking like something worth rereading.

The idea is simple: going from draft to document should feel like a change of state. You write in a plain, honest space, and you read your thinking back at its best.

## Install

**From Obsidian** (once listed): Settings → Appearance → Themes → Manage → search "Reitz LaTeX".

**Manually:**

1. Download `theme.css` and `manifest.json` from the latest release.
2. Put them in `<your vault>/.obsidian/themes/Reitz LaTeX/`.
3. Pick **Reitz LaTeX** in Settings → Appearance → Themes.
