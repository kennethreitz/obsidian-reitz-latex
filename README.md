# Reitz LaTeX

An Obsidian theme that makes your notes read like a beautifully typeset LaTeX paper.

Latin Modern for prose, IBM Plex Mono for code, generous margins, and quiet structure. Light and dark modes included. Fonts are embedded, so it works offline with no setup.

## Install

**From Obsidian** (once listed): Settings → Appearance → Themes → Manage → search "Reitz LaTeX".

**Manually:**

1. Download `theme.css` and `manifest.json` from the latest release.
2. Put them in `<your vault>/.obsidian/themes/Reitz LaTeX/`.
3. Pick **Reitz LaTeX** in Settings → Appearance → Themes.
